# Collaborative Filtering Book Recommender System

A simple book recommendation system built using Collaborative Filtering and Cosine Similarity.

## Project Overview
This is my final year academic project. The system recommends books to users based on ratings and similarity between books.

## Features
- User registration and login
- Personalized book recommendations using Collaborative Filtering
- Cosine Similarity for finding similar books
- Basic web interface using Flask

## Tech Stack
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn

## How It Works
1. User ratings data is processed
2. Similarity between books is calculated using Cosine Similarity
3. Based on the similarity scores, the system recommends books to the user
